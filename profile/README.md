# Persian-Tools

Welcome to the official GitHub organization for **Persian-Tools**. Our mission is to empower developers by creating and maintaining a comprehensive suite of high-quality, open-source libraries for the Persian language. Our tools are designed to be high-performance, easy to use, and available across a wide range of programming languages and frameworks.

## Our Ecosystem

Our ecosystem is constantly growing. Below are our core libraries and framework-specific tools.

### Core Libraries

  - **[persian-tools](https://github.com/persian-tools/persian-tools)** (TypeScript): A comprehensive toolkit for Node.js, Bun, and the browser.
  - **[py-persian-tools](https://github.com/persian-tools/py-persian-tools)** (Python): An anthology of essential tools for Python developers.
  - **[go-persian-tools](https://github.com/persian-tools/go-persian-tools)** (Go): A powerful set of utilities for Go applications.
  - **[rust-persian-tools](https://github.com/persian-tools/rust-persian-tools)** (Rust): A high-performance library for the Rust ecosystem.
  - **[dart-persian-tools](https://github.com/persian-tools/dart-persian-tools)** (Dart): A versatile library for all platforms supported by Dart and Flutter.
  - **[net-persian-tools](https://github.com/persian-tools/net-persian-tools)** (C\#): A collection of tools for the .NET framework.
  - **[java-persian-tools](https://github.com/persian-tools/java-persian-tools)** (Java): A library bringing our core utilities to the Java ecosystem.
  - **[php-persian-tools](https://github.com/persian-tools/php-persian-tools)** (PHP): Essential Persian language tools for PHP developers.
  - **[swift-persian-tools](https://github.com/persian-tools/swift-persian-tools)** (Swift): A native toolkit for iOS, macOS, and other Apple platforms.
  - **[kotlin-persian-tools](https://www.google.com/search?q=https://github.com/persian-tools/kotlin-persian-tools)** (Kotlin): A collection of helpful extension functions for Kotlin and Android.

### Frameworks & UI Components

  - **[persian-mobile-datepicker](https://github.com/persian-tools/persian-mobile-datepicker)** (React): A modern, mobile-friendly Persian date and time picker.
  - **[react-persian-tools](https://github.com/persian-tools/react-persian-tools)** (React): A set of wrapper components to easily use `persian-tools` in React.
  - **[vue-persian-tools](https://github.com/persian-tools/vue-persian-tools)** (Vue.js): A lightweight wrapper for integrating our utilities into Vue.js applications.

## Getting Started

To begin, navigate to the repository for your language or framework of choice. Each project contains a detailed `README.md` with installation and usage instructions.

For example, to install the core TypeScript library:

```bash
npm install @persian-tools/persian-tools
```
